# 💻 Common Cisco Commands

```bash
enable
configure terminal

hostname Router1

interface g0/0
ip address 192.168.1.1 255.255.255.0
no shutdown

router ospf 1
network 192.168.1.0 0.0.0.255 area 0

ip route 0.0.0.0 0.0.0.0 10.0.0.1

show running-config
show ip route
show ip interface brief
show ip ospf neighbor
show vlan brief
```
